# project3
COVID-19 Case Analysis is a Python-based data analytics project that examines the global spread of COVID-19 using publicly available datasets or APIs. The project applies Exploratory Data Analysis (EDA) and time-series analysis to study confirmed cases, deaths, recoveries, and active cases across different countries and time periods.

By analyzing pandemic data and visualizing trends, the project provides meaningful insights into the progression of COVID-19 and demonstrates how data science can be used to understand real-world public health events.
